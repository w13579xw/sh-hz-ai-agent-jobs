# 沪杭 AI 应用开发实习与校招岗位雷达

面向 2028 届及在校生／求职者，聚焦 **上海 / 杭州** 57 家国内一线大厂、外企研发中心、AI 原生独角兽与垂类龙头的 **AI 应用开发 / AI Agent / 大模型应用开发** 岗位追踪。

## 核心特性
- **地区精准筛选**：全部 / 上海 / 杭州 / 沪杭双城
- **通道精准过滤与动态列展示**：支持按 **日常实习 / 暑期实习 / 秋招** 筛选；选中通道后自动隐藏已停招或未开启企业、精简无关列，直接展示可投递的具体岗位名与直达投递链接
- **近 30 天上线筛选**：一键定位最近一个月内新上线的在招岗位
- **最新动态面板**：区分展示「新增上线岗位」与「已停招 / 招满岗位」，并标明所属通道（日常实习 / 暑期实习 / 秋招）
- **个人进度追踪 & CSV 导出**：浏览器本地持久化投递状态，支持一键导出筛选结果

## 本地预览
直接双击 `index.html` 即可在浏览器中打开使用；修改 `data.json` 后运行 `python sync_data.py` 即可同步更新 `data.js`。
